# Java Hooks

> This file extends upstream [common/hooks.md](https://github.com/affaan-m/everything-claude-code/blob/90606c8315ee09cafc303515c5f33024db6b9882/rules/common/hooks.md) with Java-specific content.

## PostToolUse Hooks

Configure in `~/.claude/settings.json`:

- **google-java-format**: Auto-format `.java` files after edit
- **checkstyle**: Run style checks after editing Java files
- **./mvnw compile** or **./gradlew compileJava**: Verify compilation after changes
