# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| N-1     | Yes       |
| older   | No        |

## Reporting a Vulnerability

**Do not open a public issue or merge request for security vulnerabilities.**

Report privately through the hosting platform's own channel:

- **GitHub:** Security tab → *Report a vulnerability* (private vulnerability reporting)
- **GitLab:** create a *confidential* issue

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

Response SLA:

- Acknowledgement within **48 hours**
- Status update within **7 days**
- Patch or mitigation within **30 days** for confirmed issues

## Out of Scope

- Vulnerabilities in third-party dependencies (report to the upstream project)
- Theoretical attacks with no practical exploit
- Issues in development-only tooling that cannot affect production
